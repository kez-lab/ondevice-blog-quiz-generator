# ❓ [12] 자주 묻는 질문(FAQ) & 실전 문제 해결 가이드

AI 모델 학습과 온디바이스 개발 중 마주칠 수 있는 대표적인 의문점들과 해결책입니다.

---

### Q1. 학습할 때 Mac 팬이 돌거나 GPU가 뜨거워지는 건 정상인가요?
* **A**: 지극히 정상입니다! M4 Pro의 16개 GPU 코어가 1초에 수조 번의 행렬 곱셈을 100% 풀로드로 처리하고 있기 때문입니다. 48GB 메모리 덕분에 발열 제어와 쓰로틀링 방어가 매우 훌륭하게 작동합니다.

---

### Q2. Loss(손실도)가 줄어들지 않거나 이상하게 튀면 어떻게 하나요?
* **A1 (학습률 체크)**: `learning_rate`가 너무 크면(예: `1e-2`) 모델이 정답을 지나쳐 튕겨 나갑니다. 보통 `2e-4` ~ `3e-4` 수준이 적절합니다.
* **A2 (스케줄러)**: 학습 후반부에 학습률을 점진적으로 줄여주는 `lr_scheduler_type="cosine"`을 적용합니다.

---

### Q3. AI가 뱉은 JSON 문법이 깨지거나 오탈자가 나면 어떻게 방어하나요?
* **A**: 우리가 작성한 [`QuizJsonParser.kt`](file:///Users/kwak-euijin/Documents/antigravity/mysterious-noether/quiz-sdk/src/main/java/io/github/quizgen/parser/QuizJsonParser.kt)처럼 **3중 방어 파서**를 구성합니다:
  1. `[ ... ]` 대괄호 영역만 정규식으로 안전하게 슬라이싱
  2. 마크다운 백틱(```json) 및 오탈자 괄호 자동 치환/보정
  3. JSON 파싱 실패 시 정규식 기반 폴백(Fallback) 키-값 추출기 동작

---

### Q4. 내 M4 Pro 맥북(48GB RAM)의 장점은 무엇인가요?
* **A**: 일반적인 16GB 맥북이나 노트북은 0.5B 모델조차 배치 사이즈를 줄여서 겨우 돌려야 하지만, **48GB 통합 메모리 환경에서는 2B~7B 모델의 LoRA 파인튜닝과 4,096 토큰의 긴 장문 컨텍스트 학습도 메모리 부족(OOM) 없이 로컬에서 즉시 수행**할 수 있는 현존 최고의 로컬 AI 개발 환경입니다.
